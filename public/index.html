HTML Core Fixture

Static HTML preview should preserve safe inline CSS.

Primary checklist

  • Headings create outline anchors.
  • Paragraphs and list items are commentable.
  • Local HTML links remain inspectable.
  • Unstyled HTML receives Commentary defaults.
  • Same-repository CSS remains available.
  • Head titles appear in navigator tooltips.

Safe inline SVG

Repository images should render without overflowing the document pane.
